# PIC 3D Viewer

X68000 の画像形式「柳沢PIC」を three.js で 3D 表示するビューアと、画像を PIC に変換するエンコーダです。
`index.html` 1 ファイルだけで動きます（three.js は CDN から読み込み）。

**デモ:** https://kumi0708.github.io/pic-3d-viewer/

## できること

### PIC の 3D 表示
| モード | 内容 |
|---|---|
| 平面 | 元の画像（X68000 の 15bit 色 / GRB 各 5bit） |
| 輝度ハイト | 明るさを高さにした地形 |
| 圧縮構造 | 変化点を最上段、連鎖を中段、ランを床に配置。PIC がどこにデータを使っているかを可視化 |
| 稲妻 | 連鎖で「先回り」して色が確定したドットを、その先行量（ビット）だけ持ち上げる |
| 色空間 | RGB 立方体に各ドットを配置 |

- 色づけ: 実色 / 種別（ラン・変化点・連鎖）/ 時刻（ファイル内の読込位置）
- デコード再生: ファイルの読み込み位置に合わせて描画が進み、確定した瞬間のドットが光る「稲妻」アニメーション
- 連鎖ラインの表示、高さ・点サイズ調整、自動回転

### 画像 → PIC 変換
- PNG / JPEG などをドロップ、または「画像を選ぶ…」で PIC に変換し、その場で 3D 表示
- サイズ（長辺 128〜1024）、色深度（15bit〜3bit）、ディザ（なし / ベイヤー / 誤差拡散）、コメント（英数字）を指定可能
- 変換結果は内蔵デコーダで読み戻して元画像と一致することを検証し、「PIC を保存」でダウンロード

## 使い方
`index.html` をブラウザで開くか、上のデモページを開いてください。
PIC ファイルはそのまま表示、それ以外の画像は PIC に変換して表示します。

## 実装について
- デコーダは [novisoftware/PicLoader2022](https://github.com/novisoftware/PicLoader2022) の Java 実装（やなぎさわ氏の PIC フォーマット仕様書に同梱の `picl.c` が元）を JavaScript に移植し、3D 表示用の計測（変化点・連鎖・確定位置）を加えたものです。
- エンコーダも同リポジトリの `PicEncoder` を元にしていますが、次の点を修正しています。
  - 「右 2 ドット」の連鎖の判定条件の誤り（`x-2` → `x+2`）
  - 色キャッシュのヒット時に LRU 順序を更新し、デコーダと同期させる
- 対応しているのは X68000 タイプ（タイプ/モード 0、15bit 色）のみです。
